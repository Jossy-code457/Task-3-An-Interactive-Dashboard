Objective
To develop an interactive dashboard using Google Looker Studio to present key findings from the cleaned Air Quality dataset and the exploratory data analysis completed in Tasks 1 and 2.

Dataset
The project uses the UCI Air Quality dataset, containing approximately 9,357 observations collected between 2004 and 2005.

The dataset includes measurements of various air pollutants and environmental variables, including:
Carbon Monoxide (CO)
Benzene (C6H6)
Nitrogen Oxides (NOx)
Nitrogen Dioxide (NO2)
Temperature (T)
Relative Humidity (RH)

Tools Used
Microsoft Excel – Data cleaning and exploratory data analysis.
Google Sheets – Preparation of summary statistics.
Google Looker Studio – Interactive dashboard development.

Dashboard Features

The dashboard includes:
Summary statistics for selected air quality parameters.
Time-series visualizations showing pollutant variations over time.
Histograms showing the distribution of selected variables.
A scatter plot examining the relationship between temperature and relative humidity.
A pie chart presenting the relative proportions of selected average parameter values.
Date range and date drop-down controls for filtering the dashboard.

Key Insights
The dashboard provides an overview of pollutant concentrations, their variations over time, and the distribution of selected air quality measurements. It also allows users to explore patterns in the dataset through interactive filters and visualizations.

Project Outcome
This task provided practical experience in transforming analyzed data into an interactive visual dashboard. It strengthened my skills in data visualization, dashboard design, and communicating analytical findings.
